# DualSlide 0.5.4

- Keep both shows on the last slide, with animations preserved. Navigate backward and forward without restarting; press Escape to exit.
- Fix the distorted audience arrow by using the native cursor with correct transparency, hotspot, and display scaling.
- Improve the audience laser with a centered red ring and soft halo. It remains an approximation of PowerPoint's laser; custom laser colors are not mirrored.
- Close an empty PowerPoint process started by DualSlide after you exit. Existing PowerPoint sessions and open presentations stay untouched.

Download and extract `DualSlide-0.5.4.zip`, then run `DualSlide.exe`. Requires Windows 11 x64, desktop PowerPoint, and two extended displays.
