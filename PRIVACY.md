# DualSlide privacy policy

Effective October 25, 2026. Publisher: Silviu Vlasceanu.

DualSlide runs locally on your Windows PC. It does not include analytics, advertising, account registration, or automatic transmission of your presentations, pointer movements, or usage data to the publisher.

You choose two presentation files. DualSlide opens them through the installed Microsoft PowerPoint desktop application, read-only, and synchronizes their live slideshows. DualSlide does not upload the files or save changes to them.

DualSlide stores selected presentation paths, display choices, recent presentation pairs, and diagnostic logs locally under the current user's application-data folder. Diagnostics may include file paths and error details. This information is not automatically sent anywhere. Uninstalling the Store package removes its private app data; data from a separately installed portable version may remain under `%LOCALAPPDATA%\DualSlide` and can be removed manually.

While a paired show is active, DualSlide uses Windows keyboard/mouse hooks to handle slideshow navigation and Escape, and samples pointer position to mirror the pointer. These events are not uploaded or recorded as a keystroke history. Hooks are removed when the session ends.

The GitHub link opens your browser only when selected. Microsoft PowerPoint, Windows, Microsoft Store, and websites you open have their own privacy policies.

If you choose to send diagnostics or attach a presentation to a public GitHub issue, that is a separate, user-initiated disclosure. Review files and redact private paths before sharing them.

Questions and support: https://github.com/silviuk/DualSlide/issues
